# Amazon Vine Review Analysis

An NLP project for **INST425: AI for Text Analysis** at the University of Maryland.

## Overview

This project explores how Amazon Vine reviews differ from non-Vine reviews in terms of ratings, sentiment, and language. We focus on beauty products to investigate whether reviewers who receive free products provide more detailed and balanced feedback.

## Dataset

We use the **Amazon US Customer Reviews – Beauty** dataset.

Our initial exploratory data analysis (EDA) identified:
- **5M+** total reviews
- **33,213** Vine reviews
- **1,003** products with at least 5 Vine and 5 non-Vine reviews

## Methods

- Exploratory Data Analysis (EDA)
- Sentiment Analysis
- TF-IDF and N-gram Analysis
- Text Classification using Logistic Regression
- Data Visualization and Model Evaluation

## Tools
Python, pandas, NLTK, scikit-learn, Matplotlib
